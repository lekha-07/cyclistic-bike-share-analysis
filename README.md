# 🚴 Cyclistic Bike-Share Analysis

## Google Data Analytics Professional Certificate Capstone Project

### Project Overview

This project is the capstone project for the Google Data Analytics Professional Certificate.

The objective is to analyze Cyclistic bike-share data and provide data-driven recommendations to help convert casual riders into annual members.

---

## Business Task

Cyclistic's marketing team wants to understand how casual riders and annual members use bikes differently.

The goal of this analysis is to identify customer behavior patterns and recommend strategies that encourage casual riders to purchase annual memberships.

---

## Dataset

- Source: Divvy (Cyclistic) Bike Share Data
- Time Period: October 2024 – September 2025
- Dataset Size: Approximately 1 GB
- Data Type: 12 monthly CSV files

> **Note:** The original dataset is not included in this repository due to GitHub file size limitations.

## Data Cleaning

The dataset was cleaned by:

- Combining 12 monthly datasets
- Removing duplicate records
- Handling missing values
- Converting date columns
- Creating ride duration
- Extracting weekday, month, and hour features
- Removing invalid ride durations

---

## Exploratory Data Analysis

The following analyses were performed:

- Ride distribution by user type
- Average ride duration
- Weekly riding trends
- Monthly riding trends
- Hourly riding patterns

---

## Key Insights

- Annual members completed significantly more rides.
- Casual riders had longer average ride durations.
- Casual riders primarily rode on weekends.
- Member rides showed strong weekday commuting patterns.
- Ridership increased during the summer months.

---

## Business Recommendations

- Offer weekend membership promotions.
- Launch seasonal marketing campaigns.
- Provide discounted membership trials.
- Reward frequent casual riders.
- Promote long-term membership savings.
